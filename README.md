# Breakout (Human vs AI Testing)

## Run the Windows `.exe` builds

To run both games, use the release ZIP files for **Game 1** and **Game 2**.

1. Open the repository **Releases** page.
2. Download the ZIP for the **Game 1** release.
3. Download the ZIP for the **Game 2** release.
4. Extract each ZIP file.
5. In each extracted release folder, open the **Build** folder 
6. Run the `.exe` file from that Build folder:
   - `Game 1.exe` for Game 1
   - `Game 2.exe` for Game 2

If Windows shows a SmartScreen warning, click **More info** → **Run anyway**.
